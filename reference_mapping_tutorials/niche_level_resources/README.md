nichecompass_ref_mapping_preparation.ipynb has steps to prepare the dataset prior to running nichecompass (in a reference query style).

A full tutorial is available here:
https://nichecompass.readthedocs.io/en/latest/tutorials/notebooks/mouse_cns_spatial_reference_mapping.html

In run_nichecompass_script, we provide the code we used for reference-query mapping.
